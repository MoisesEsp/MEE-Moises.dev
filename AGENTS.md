# AGENTS.md — web persoanl
Web personal estatica para añadir a mi curriculumen que servira para mostrar mis aptitudes y habilidades como desarrollador junior. Proyecto didáctico: el código debe poder entenderlo alguien que empieza a programar.
## Stack y estructura
- HTML, CSS puros: sin frameworks, librerías, npm, bundler ni build.
- `index.html` (estructura), `styles.css` (estilos)
- debe estar pensado para subirlo a github pages
- la informacon que se usara en la paguina esta en el archivo `InfPersonal.md`
## Convenciones
- Textos de la interfaz, mensajes y documentación en español.
- Código (identificadores y comentarios) en inglés; nombres descriptivos y comentarios
  solo donde aporten.
- Diseño limpio y responsive; cualquier pantalla nueva debe verse bien en el móvil.
- Estilo intefaz omarchy theme wallhaven
- para animaciones de scroll usa la nueva actualizacion de css scroll driven animations
## Forma de trabajar
- Haz solo lo que se pide: no añadas funcionalidades por tu cuenta.
- Cambios pequeños y enfocados; no reescribas lo que ya funciona.
- Al terminar, resume qué has cambiado y cualquier decisión que deba revisar.
## Memoria
- Al empezar, lee `MEMORY.md` para conocer el estado del proyecto y las decisiones
tomadas.
- Al terminar una tarea, actualízalo: estado actual, decisiones importantes (con su
porqué) y errores a evitar.
- Mantenlo breve (máximo ~50 líneas): resume o elimina lo que ya no aporte.
- Si algo se convierte en una regla permanente, propón moverlo a `AGENTS.md` en lugar de
dejarlo en la memoria.
- No guardes nunca datos sensibles (claves, tokens, datos personales)
## Git - github
- si te pud hacer un commit o push, primero me mostraras una recomendacion de commit
- si apruebo tu recomendacion de commit lo aras y pediras permiso para hacer el push
## Límites
- ✅ Siempre: actualizar `MEMORY.md` al terminar cada tarea.
- ⚠️ Pregunta antes: crear archivos nuevos, cambiar el formato de los datos guardados.
- 🚫 Nunca: añadir dependencias, frameworks o un paso de build.
## Verificación
- Después de cada cambio, verifica la interfaz con el MCP de Chrome DevTools: abre
`index.html`, prueba la nueva integracion, revisa la consola y comprueba 375 px.
